Implemented behavior

Member/equipment search commands carry immutable criteria through typed directory display requests. Real lists, selection recovery and summaries use the same current-data query as command feedback. Partial text, combined filters, selectable deterministic sorting, reset with list commands, zero-result hints, identity-preserving rows and detail navigation are covered. Loan-only changes re-evaluate holding/availability filters. Inventory groups include every current physical unit independently of the filter. Advisory duplicate feedback includes existing identities without blocking legitimate units.

Search never calls saving, even when the storage implementation deliberately rejects every write. Real temporary JSON tests compare records, collection order, saved bytes and fresh-model reloads. Successful additions still use the existing transaction/persistence pipeline and retain every identity. No new domain schema, lifecycle state, undo history, transfer service or shared CSS was introduced.
