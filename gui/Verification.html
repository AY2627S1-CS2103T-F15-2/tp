Stage A foundation

The foundation branch supplies shared styles and a JavaFX test helper. It does not implement the application shell, deletion commands, directory panels, or final milestone acceptance. Those require the other contributors' merged contracts and components.

Use Java 25 and the repository Gradle wrapper. On macOS with SDKMAN, the configured JDK is sdk use java 25.0.3.fx-zulu. Tests deliberately load the declared JavaFX 17.0.7 runtime instead of any JavaFX version bundled with the JDK. The test-only configuration chooses mac-aarch64/mac, linux-aarch64/linux, or win according to the host OS and architecture. The existing production dependencies and dependency versions are preserved.

A desktop graphical session is required on macOS and Windows. Linux CI uses Xvfb:

xvfb-run --auto-servernum ./gradlew check coverage

For local focused checks and the complete validation:

./gradlew test --tests seedu.address.testutil.FxTestUtilTest --tests seedu.address.ui.LaplaceThemeTest
./gradlew check coverage shadowJar
./.github/run-checks.sh

There are no graphical-test skips or headless-success substitutions. Native/display failures are failures. The Linux, macOS and Windows workflow jobs remain in place, including coverage. Local macOS validation alone does not establish that the other workers passed.

Shared component APIs

Use FxTestUtil.runAndWait(Runnable) for FXML creation, Node updates and GUI assertions. It starts one toolkit per JVM, awaits real completion signals, propagates original failures, supports nested calls on the FX thread, and keeps the toolkit alive after a window closes. Concurrent callers share startup. Interruptions preserve the interrupt flag and cancel a queued action; an already running action cannot be rolled back. The completion timeout is 30 seconds. Close each test's windows in finally; never call Platform.exit() between tests.

Load /view/LaplaceTheme.css from the classpath and add laplace-root to the scene root. Standalone previews should use that same root class. Do not add the old global dark theme to the same scene; load dark styles locally for legacy/help content when the shell is integrated.

Style class Purpose
laplace-surface White bordered panel
laplace-title Main heading
laplace-muted Secondary information with readable contrast
laplace-count-badge Rounded count/status badge
laplace-header Charcoal navigation header
laplace-navigation Keyboard-focusable navigation button
laplace-navigation-active Active navigation text weight and underline
laplace-success Green feedback/status container
laplace-error Red feedback container and readable error text
laplace-row Padding/spacing for immutable row content

ListView selection styling is scoped below laplace-root, including selected rows when the list loses focus. The parent ListView owns selection and callbacks; a card uses laplace-row for its content. Feature-specific classes retain the agreed member/equipment/loan/directory/ details prefixes. Text fields support the existing error class. Labels with long content must use wrapping, and each component remains responsible for scrollable layout.
