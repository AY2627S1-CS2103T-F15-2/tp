Compact layout verification — PR #322
Verified 1 November 2026 (Singapore time)

Regression target
One complete first open-loan card from the shipped sample data must fit
without scrolling at 853x400 logical pixels, including status, both
identities, dates, issue condition, observed return condition and Prepare
return command. Further cards remain reachable through scrolling.
Two complete member/equipment directory rows and two physical-unit rows
are checked separately; visibility assertions are not relaxed.

Linux environment
Docker Desktop Linux x86_64 under AMD64 emulation on Apple Silicon.
Temurin 25.0.5+8, GTK 3, Xvfb -screen 0 1280x720x24.
The test JVM uses -Dglass.gtk.uiScale=1.5 and
-Dlaplace.requiredScale=1.5. Shell setup asserts actual output scale 1.5
and screen bounds matching 1280x720 divided by that scale.
Production classes, FXML, CSS and natives load from the candidate JAR.
JUnit Console 1.14.4 runs the compiled test helpers with no development
production classes or external JavaFX libraries on the classpath.
